# Amazon-Shipping-Analysis-Tableau-Dashboard
Project Overview

This project presents an interactive Amazon Shipping Analysis Dashboard built using Tableau. The dashboard provides insights into shipping performance, delivery timelines, regional distribution, and operational efficiency.

The goal of this project is to analyze shipping data to identify patterns, delays, and improvement opportunities in logistics operations.

📊 Key Objectives

Analyze shipping performance across different regions

Measure delivery time and shipping delays

Identify high-performing and low-performing shipping zones

Track order volume trends

Evaluate shipping cost distribution
